# 読みやすいフロントエンド参照用ソース

ここには `public/` の自作JavaScript・CSS・HTML・JSONを改行・字下げした参照用コピーを置いています。ブラウザーへの配信には使いません。`public/` の内容は整形前とバイト単位で同一のため、転送量や動作は変わりません。

修正を反映する際は `public/` 側も更新してください。このフォルダーだけを編集しても画面には反映されません。外部ライブラリーをまとめた `public/qr.js` は整形対象外です。

PHPは `private/` と `public/index.php` 自体を整形しています。SQLや文字列の内容、実行トークンは変更していません。
